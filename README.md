# Bureaucrats

A focused CSS preparation companion for Pakistan's Central Superior Services examination.

## Project status

Initial repository bootstrap. The first implementation milestone is the Essay Examiner foundation: Flutter client structure, Supabase schema with row-level security, and a server-side evaluation function. This is not yet a production release.

## Planned modules

- Secure account and profile
- FPSC-aligned essay examiner
- Pakistan Affairs and Current Affairs learning feed
- MCQ practice with server-controlled answer validation
- Syllabus and study progress
- Subscription entitlements verified server-side

## Safety and integrity

Never put Supabase service-role keys or AI provider keys in the Flutter app. Configure secrets only in the Supabase project. AI-generated marks are practice feedback, not an official FPSC result.
